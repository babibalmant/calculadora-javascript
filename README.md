## ⚡ Funcionalidades

- ➕ **Operações Básicas:** Soma, subtração, multiplicação e divisão.
- 🧹 **Clear & Backspace:** Opções para limpar a tela ou apagar o último dígito inserido.
- 📱 **Interface Intuitiva:** Layout limpo e responsivo inspirado em calculadoras modernas.
